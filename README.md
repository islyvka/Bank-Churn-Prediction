# Прогнозування відтоку клієнтів банку (Bank Churn Prediction)

### Опис проєкту
Цей проєкт присвячений розробці моделі машинного навчання для ідентифікації клієнтів, які з високою ймовірністю можуть припинити користування послугами банку. Проєкт демонструє повний цикл роботи з даними: від очищення до збереження готової моделі для подальшого використання.

---

### 📂 Структура репозиторію
* **`Bank_Customer_Churn_Prediction.ipynb`**: Jupyter Notebook з детальним EDA та побудовою моделі.
* **`data/`**: Оброблений набір даних у форматі **Parquet** (використано для оптимізації пам'яті та збереження типів даних).
* **`models/`**: Збережена модель логістичної регресії (`.joblib`).

---

### 🛠 Ключові етапи роботи

#### 1. Дослідницький аналіз даних (EDA)
* Аналіз розподілу ознак та виявлення кореляцій за допомогою `Pandas`, `Matplotlib` та `Seaborn`.
* Пошук залежностей між фінансовим профілем клієнта (баланс, кредитна історія) та ймовірністю відтоку.

#### 2. Підготовка даних
* **Очищення**: Видалення неінформативних ознак (`CustomerId`, `Surname`).
* **Кодування**: Трансформація категоріальних змінних через One-Hot Encoding.
* **Скейлінг**: Масштабування числових ознак через **MinMaxdScaler**, що є критичним для коректної роботи регресійних моделей.

#### 3. Моделювання
* Побудова моделі **логістичної регресії** для класифікації.
* Оцінка якості моделі за допомогою метрик **Accuracy**, **F1-Score**, **ROC-AUC** та аналізу матриці помилок.
